# Booking Wizard – Multi-Step Appointment Form

A multi-step appointment booking wizard built with **React**, **Redux Toolkit**, and **Tailwind CSS**.

## ✨ Features
- 4-step booking flow:
  1. Select Staff
  2. Select Service
  3. Choose Date & Time
  4. Confirmation with user details
- State management with Redux Toolkit
- Persistent state using LocalStorage (data survives page refresh)
- Responsive UI built with Tailwind CSS
- Clean and scalable project structure

## 🛠 Tech Stack
- React (Vite)
- Redux Toolkit
- Tailwind CSS
- LocalStorage API
